Caliape Recorder Integration API

Documentación oficial para integrar Recorder Web con los flujos Enterprise de Caliape: sesiones efímeras, carga de audio, procesamiento y resultados con trazabilidad.

  • Carga de audio, procesamiento de cases y consulta de outputs canónicos por tenant.
